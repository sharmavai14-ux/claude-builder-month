# House report style

Every report has exactly these five parts, in this order:

1. A title line: `# Report: <topic>`
2. `## In one line`: one sentence that says the most important thing.
3. `## What happened`: 3 to 5 short bullet points.
4. `## What's next`: bullet points. Each one says who does it and by when.
   If nobody is named, write "Who: not decided".
5. `## Open questions`: anything that is unclear in the notes.
   If there is nothing, write "None".

Then one last line in italics: `_Written by my report agent on <today's date>_`

Rules:
- Keep the whole report under 200 words.
- Only use facts that are in the notes. Never invent names or dates.
